# Performance Baselines

This directory holds the historical performance baseline used for regression
detection in the Ketoan ERP backend.

## Files

- **`baseline.json`** — committed snapshot of measured benchmark durations
  (milliseconds). Generated by `npm run perf:update-baseline`.
- **`measure.mjs`** — shared measurement helpers (`measure`, `getTaxRate`,
  `calculateBQGQ`, `calculateFIFOCost`, `formatCurrency`). Imported by both the
  Jest budgeted-benchmarks test and `scripts/perf-regression.mjs` so the numbers
  always come from identical code.

## How Regression Detection Works

`scripts/perf-regression.mjs` (run via `npm run perf:check`) measures the four
core benchmarks and compares each against `baseline.json`:

```
limit = baseline * (1 + tolerance)
regression if measured > limit
```

The **tolerance** defaults to **20%** and is configured in
`tests/perf-budgets.json` under `_ci.regressionTolerancePct`. A regression makes
the script exit non-zero so CI fails.

> Note: micro-benchmarks are noisy. The 20% tolerance absorbs normal variance
> (GC pauses, CPU scheduling). Only sustained, significant slowdowns should trip
> the check. If a genuine, intentional speedup or slowdown is made, regenerate
> the baseline (below) and commit it.

## Workflow

```bash
# 1. Check for regressions against the committed baseline
npm run perf:check

# 2. After an intentional performance change, refresh the baseline
npm run perf:update-baseline
git add tests/perf-baselines/baseline.json
git commit -m "chore: refresh performance baseline"
```

## CI Integration

The dedicated `test.yml` GitHub Actions workflow runs `npm run perf:check` after
the budgeted Jest test, so a regression blocks the merge automatically.

## Benchmark Keys

| Key | What it measures |
|-----|------------------|
| `taxRateTenThousandLookups` | 10k progressive tax-rate lookups |
| `bqgqTenThousandCalculations` | 10k weighted-average (BQGQ) cost calcs |
| `fifoTenThousandCalculations` | 10k FIFO cost-of-goods-sold calcs |
| `formatCurrencyTenThousand` | 10k VND currency formatting calls |
